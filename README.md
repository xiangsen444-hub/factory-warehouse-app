# 工厂仓库管理系统（演示版）

用 Streamlit + SQLite 做的轻量仓库管理系统，最初是为解决工厂手工登记出入库、Excel 找料号慢的问题写的。这份是脱敏演示版：客户名称已替换成客户A/B/C/D/E，不含任何真实企业信息。

## 功能

- **库存查询**：搜索料号/客户，低库存自动标红，点击查看物料详情（含产品照片/图纸）
- **库位视图**：按库位分组展示，方便按位置盘点
- **入库 / 出库登记**：记录每次出入库，自动校验库存不足
- **出入流水**：全部出入库记录，可导出 CSV
- **AI 问答**：基于库存数据的离线规则问答（不依赖外部 API）
- **物料管理**：支持 Excel 批量导入、物料信息编辑、盘点差异自动生成流水
- **权限控制**：查询类功能公开，入库/出库/物料管理等编辑功能需密码解锁；解锁状态也支持通过带密钥的链接免密访问

## 技术栈

- Streamlit（前端 + 后端一体）
- SQLite（单文件数据库，零配置）
- pandas / openpyxl（Excel 导入导出）

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```
